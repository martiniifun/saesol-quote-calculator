# 수출 견적 계산기

새솔물산(가상 회사) 해외영업팀용 수출 견적 계산기입니다. 설치·빌드·서버 없이 브라우저에서 바로 열어 씁니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다 (더블클릭, `file://`에서 동작).
2. 품목, 조건(FOB / CIF), 수량, 마진율, 환율을 입력합니다.
   - CIF를 고르면 도착 지역(일본 / 동남아)을 추가로 선택합니다.
   - 환율(원/USD)과 엔화 환율(원/100엔)은 실제 환율이 아니라 **입력값**입니다.
3. 결과에서 박스 수, 원가, 견적가(원·USD·JPY)를 확인합니다.
4. 인쇄하면 A4 견적서(USD 총액)가 출력됩니다.

## 계산 규칙

- 반올림은 `Math.round`(0.5는 올림), USD는 소수 둘째 자리까지.
- FOB 원가 = 상품 금액 + 포장비(박스당 1,200원) + 내륙 운송비(박스당 800원)
- CIF 원가 = FOB 원가 + 해상운임(박스당 일본 1,800원 / 동남아 2,500원) + 보험료(FOB 원가의 0.2%)
- 견적가 = 기준 원가 × (1 + 마진율)

자세한 내용은 [요구사항.md](요구사항.md)를 참고하세요.

## 테스트

```
node test.js
```

프레임워크 없이 `assert`만 사용하며, `요구사항.md`의 예시 A(CIF), 예시 B(FOB)를 검증합니다.

## 단가표 수정 시 주의

단가표가 `단가표.csv`와 `index.html` 안의 `CSV` 문자열 두 곳에 있습니다. `file://`에서는 CSV를 불러올 수 없어 내장했기 때문에, 품목을 바꾸면 **두 곳 모두** 고쳐야 합니다.
